# viral

Skill do Claude Code que dá estrutura narrativa viral e um padrão de edição reproduzível (HTML/GSAP + ffmpeg) aos roteiros e vídeos do Adriel, a partir dos 15 reels mais vistos e dos 15 mais recentes de @kallawaymarketing (coleta de 30/09/2026) e do vídeo "The Neuroscience of Addictive Storytelling". Funciona sozinha ou junto com a skill /modelagem.

## Instalar

```bash
git clone https://github.com/kairoxaioficial/skill-viral.git ~/.claude/skills/viral
```

## Usar

```
/viral roteiro <tema>
/viral revisar <roteiro>
/viral gancho <tema>
/viral edicao <video.mp4>
```

Instruções completas em `SKILL.md`; análise em `references/`.
